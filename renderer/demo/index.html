GaussianSlim Compact Gaussian Web Viewer
This Three.js-based viewer loads bundled GaussianSlim Compact Gaussian scenes, based on 3D Gaussian Splatting, directly in the browser. GaussianSlim scenes are packaged as .glb assets and use the available ASTC, BC, or CPU texture path selected for this browser.

Choose a bundled GaussianSlim scene below, or use the local-file viewer for .glb, .ply, .ksplat, and .splat files.
